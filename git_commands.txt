Git Commands Used in SDP Graded Assignment 2
=============================================

1. git init -b main
   Creates a new local Git repository in the project folder and sets the default branch name to main.

2. git add index.html about.html
   Stages the initial HTML files so Git tracks them for the next commit.

3. git commit -m "Add initial index and about pages"
   Records a snapshot of the staged files in the repository history with a commit message.

4. git add index.html
   Stages the updated index.html file after adding navigation links.

5. git commit -m "Add navigation bar to index page"
   Creates a second commit on the main branch for the updated home page.

6. git branch feature
   Creates a new branch named feature from the current commit on main.

7. git checkout feature
   Switches the active working branch from main to feature.

8. git add about.html
   Stages the modified about.html file on the feature branch.

9. git commit -m "Add navigation and assignment details to about page"
   Records the changes to about.html as a commit on the feature branch.

10. git checkout main
    Switches the active working branch back to main.

11. git merge --no-ff feature -m "Merge feature branch into main"
    Merges the feature branch into main and creates a merge commit so branch history stays visible.

12. git log --oneline --graph --decorate --all
    Displays the full commit history as a compact branch graph across all branches.

13. git status
    Shows the current branch, staged changes, untracked files, and confirms ignored files do not appear.

14. git status --ignored -s
    Lists untracked and ignored files in short format to verify that .gitignore rules match debug.log and temp/.

15. git add .gitignore
    Stages the .gitignore configuration file for commit.

16. git commit -m "Add gitignore for log files and temp folder"
    Saves the .gitignore rules in the repository history.

17. git add draft_notes.txt
    Stages a temporary file to prepare the commit for the undo step.

18. git commit -m "Add temporary draft notes"
    Creates an additional commit that will be undone in the next step.

19. git revert --no-edit HEAD
    Undoes the last commit by creating a new inverse commit that removes draft_notes.txt while keeping history intact.

20. git remote add origin git@github.com:SammyUrfen/sdp-sga2-git-workflow.git
    Links the local repository to the public GitHub repository under the remote name origin.

21. git push -u origin --all
    Pushes all local branches (main and feature) and their full commit history to GitHub and sets upstream tracking.
